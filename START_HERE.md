## You're seeing a PowerShell error? No problem!

I've created batch files that work around this issue.

---

## ⚡ Quick Start (3 Steps)

### Step 1: Double-click this file
```
start-both.bat
```
This will open two windows (backend + frontend)

### Step 2: Wait 20 seconds
Watch for these messages:
- Backend: "Server running on port 5000"
- Frontend: "Ready on http://localhost:3000"

### Step 3: Open your browser
```
http://localhost:3000
```

---

## 🎯 Try It Out

1. Enter a domain: **stripe.com**
2. Click "Analyze Prospect"
3. Wait 15-30 seconds
4. See the AI analysis!

## 📁 Files You Can Double-Click

| File | What It Does |

| **start-both.bat** | Starts backend + frontend (recommended) |
| start-backend.bat | Starts backend only |
| start-frontend.bat | Starts frontend only |
